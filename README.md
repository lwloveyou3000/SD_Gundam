# SD 高达 G 世纪永恒 · ADB 挂机工具

带中文桌面界面的 Python 工具。先在游戏中选好关卡，再设置完成次数或无限循环。识别固定按钮和页面文字，不依赖关卡背景、机体图片、分数或奖励内容。

## 本机启动

双击 **启动挂机.cmd**。本机已经有可用的 Python 和依赖，可以直接启动。

启动入口会检查环境是否包含依赖；安装中断留下的不完整 `.venv` 会被跳过。两个 `.cmd` 使用 ASCII 内容与 Windows CRLF 换行，命令行提示为英文，程序界面仍为中文。

1. 雷电中打开游戏，手动选好要刷的关卡，并提前开启游戏的 **AUTO**。
2. 在工具中点 **刷新**，选择雷电设备（本机通常是 `emulator-5554`）。
3. 输入完成次数，或勾选 **无限循环**，然后点右上角的 **开始**。连接和游戏页面会在启动时自动检查。

默认 ADB 路径：`F:\leidian\LDPlayer9\adb.exe`。可用「浏览」选择其他位置。

## 战利品统计

原游戏画面区域已改为战利品统计，显示道具图标、本轮数量、累计数量、出现轮数和金币累计。

道具缩略图按奖励背景框截取完整方形卡片，并依实际边框微调居中位置；道具识别使用独立的图像区域，边框和卡片上的数量不会改变道具分类。图标为31×31，表格行高38，包含行列分割线，名称与数量居中显示。名称列按4个中文字、数量列按7位数字预留宽度；累计数量包含千位分隔符的显示空间，出现轮次列与累计数量列等宽。

窗口默认900×680，连接、次数和挑战状态合并在上方两行，次数设置、循环选项及运行状态按三列对齐并带边框，使用文字显示完成次数。操作按钮在右上角垂直居中，运行提示位于左上角。战利品统计区域在紧凑布局基础上加宽约30%，表格文字列随区域扩展，剩余横向空间及原挑战状态区域用于运行记录。统计表和运行记录可随窗口增高显示更多内容。

- 每次点 **开始**，统计从零开始；暂停、继续和停止保留本次结果。
- 每场战斗的奖励只统计一次。停留在同一奖励页面不会累加；下一场获得相同道具会继续累加。
- 同一场中出现多个相同道具卡片时，数量合并计算。例如两张各 ×2，计入 ×4。
- 道具先按图标识别，名称显示为「道具01」等编号；金币单独识别。数量看不清时显示「待确认」，累计只包含已确认的数量。
- 「本轮数量」指最近一次结算；本轮没获得的道具显示0。「出现轮数」表示该道具在几场奖励中出现。
- 数字识别在本机 CPU 上完成。

## 自动流程

已选关卡 → 出击准备 → 出击 → 点击 TAP TO NEXT → 等待自动战斗 → 分数结算继续 → 经验结算继续 → 战斗奖励。

- 图3的文字会闪烁，识别已兼容这种明暗变化；识别后及时点击，不等待30秒自动跳过。
- 达到指定次数后，停在最后一轮的奖励页，**不再点击再次出击**。
- 无限模式在奖励页点击再次出击，然后重复同一关卡。
- 可从已选关卡、出击准备、TAP TO NEXT 或正在自动战斗的页面启动。
- 不从已经打开的奖励页直接启动，以免把上一轮误算为新完成次数。先选择关卡或进入下一场战斗。
- 暂停/停止只控制脚本；已开始的游戏 AUTO 战斗仍会继续。
- 战斗期间不发送操作。出现体力不足、网络提示、人机验证等未知页面时不会自动确认、补充体力或购买；等待超时后停止并保存诊断截图。

## 适用范围

当前模板针对**国际服中文界面、横屏16:9流程**。不同关卡背景、部队、舰船、分数和奖励不影响固定UI识别。截图会归一化后识别，点击映射回模拟器实际分辨率；缩放雷电的桌面窗口不会改变ADB坐标。

游戏更新更改按钮布局、字体或界面语言后，可能需要更新 `assets/profiles/default` 中的模板。识别不确定时会停止，不会凭坐标盲点。

使用时保持游戏在模拟器前台，并保留当前正常登录所需的网络配置。切换关卡前先停止脚本。

## 其他电脑 / 安装依赖

需要 Python3.10、3.11或3.12，包含 Tkinter。双击 **安装依赖.cmd** 创建本项目的 `.venv` 并安装依赖；环境会复用已安装的基础环境依赖，减少重复下载。安装成功前不会报告完成；完成后再双击启动入口。旧版本升级后应重新运行安装入口，以安装本地数字识别依赖。

也可以在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 只读检查与命令行

只读截图和识别，不点击游戏：

```powershell
python app.py --check --device emulator-5554
```

从命令行刷2次：

```powershell
python app.py --run --device emulator-5554 --rounds 2
```

无限循环可使用 `--run --infinite`，按 Ctrl+C 停止。

设置保存在 `settings.json`，错误截图和运行记录在 `logs/`。两者不会被提交到Git。

## 验证

自动测试：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

测试覆盖页面识别、不同背景和截图尺寸、闪烁文字、遮罩弹窗、有限/无限计数、重复画面、暂停/停止、等待超时、GUI状态和战利品统计。战利品使用参考奖励图及实际ADB奖励截图验证，覆盖数量、相同道具合并、不同颜色道具区分和无法确认的数量。开发时还在本机雷电实测了两轮完整循环，确认最终计数为2并停在奖励页；单独确认了TAP点击后约1.6秒进入BATTLE START。

## 文件

- `app.py`：启动入口和命令行。
- `gget_runner/adb.py`：ADB连接、截图和输入。
- `gget_runner/vision.py`：固定文字/按钮识别。
- `gget_runner/runner.py`：挂机流程、计数和停止控制。
- `gget_runner/ui.py`：中文界面。
- `gget_runner/loot.py`：本地奖励读取和本次运行的收益汇总。
- `assets/profiles/default/`：页面模板与点击位置。
- `assets/loot/`：奖励页与金币识别模板。
- `tests/`：验证用例。
- `tools/build_profile.py`：开发时从原始参考截图生成模板；日常运行不需要原始截图或此工具。

实现参考：[Android ADB](https://developer.android.com/tools/adb)、[OpenCV模板匹配](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)。
